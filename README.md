#  Football Manager

A football management project developed in Python.

## About the project

Football Manager is a personal project currently under development, created to practice programming logic, code organization, and object interaction. The goal is to gradually build a football management game where players can manage a real-world football club.

## Features

- Player creation
- Team management
- Player lineup management
- Player energy system

## Technologies

- Python
- Git e GitHub

## Note

- This project is still in the early stages of development.
